# Security policy

Thank you for helping keep techmediaarch.com and its readers safe.

## Reporting a vulnerability

Please report security issues privately — do not open a public issue.

- Preferred: use GitHub's **"Report a vulnerability"** button under the repository's **Security** tab (private vulnerability reporting).
- Or email **info@techmediaarch.com** with "Security" in the subject.

Please include what you found, where (address or file), and how to reproduce it. You will get a reply as soon as possible, usually within a few days.

## Scope

- The website techmediaarch.com (static pages served by Cloudflare Workers).
- The code in this repository, including the GitHub Actions workflows.

Out of scope: third-party services the site links to or embeds, and reports from automated scanners without a demonstrated impact.
