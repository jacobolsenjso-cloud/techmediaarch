<p>Tech Media Arch is an archive of checked answers to tech questions, run by Jacob S. Olsen from Denmark. This page explains how the answers are made, what rules they follow, and what to do if you find an error. It describes what actually happens, not what we would like to happen.</p>
<h2>Five shelves</h2>
<p>Every answer sits on one of five shelves: <a href="/shelf/ai">AI Tools &amp; Agents</a>, <a href="/shelf/cybersecurity">Cybersecurity</a>, <a href="/shelf/software">Building Software</a>, <a href="/shelf/marketing">Marketing &amp; SEO</a> and <a href="/shelf/everyday-tech">Everyday Tech</a>. Each shelf has a short "Start here" list for readers who are new to the subject.</p>
<h2>How an answer is laid out</h2>
<ul>
<li><strong>The question is the title.</strong> New answers use the question people search for as the headline.</li>
<li><strong>The short answer comes first.</strong> The first paragraph answers the question directly. The details, examples and a FAQ follow below it.</li>
<li><strong>A verification record at the bottom.</strong> It shows when the answer was published and updated, how many named sources it uses, and whether it was written with AI.</li>
</ul>
<h2>Two kinds of articles</h2>
<ul>
<li><strong>Older articles</strong> (before late September 2026): Jacob chose each subject and the search phrases it answers.</li>
<li><strong>AI-written answers</strong> (from late September 2026): written by a language model (Google Gemini) following the rules below. They are published automatically, and Jacob does not read every answer before it goes live. Each of these says so in the box about how it was made and in the verification record.</li>
</ul>
<h2>How an AI-written answer is made</h2>
<ol>
<li><strong>A real question.</strong> It starts from questions people type into Google. The robot prefers the shelf with the fewest answers, and questions an existing answer already covers are skipped, so the site does not publish the same answer twice.</li>
<li><strong>Research first.</strong> The language model searches the web and collects facts before it writes. If fewer than two sources can be found and opened, the answer is rejected.</li>
<li><strong>Sources you can check.</strong> Every source is opened and checked before the answer is written, and the answer is written only from facts found in sources that passed. Those sources are listed at the end under "Sources", and the text names only sources from that list. Some older answers also name sources that are not on their list.</li>
<li><strong>Checks before publishing.</strong> An answer is rejected if it claims personal testing or experience ("I tested"), has too few sources, is too thin, or contains visible formatting errors. Sentences with vague sources such as "experts say" are sent back to be rewritten with a named source.</li>
<li><strong>Links.</strong> Links inside the text go only to sources that were checked, or to other answers on this site about a related subject.</li>
<li><strong>Images.</strong> Images are illustrations made with AI, under rules that forbid real people, text, numbers and charts, so they are not mistaken for evidence. Answers do not embed videos.</li>
</ol>
<h2>Independence and money</h2>
<p>Tech Media Arch earns money from ads placed automatically by Google and from affiliate links in some articles. Every article carries an affiliate disclosure, and articles built around affiliate or referral links (Resources) have it at the top. Nobody can pay to be covered or to get a favorable review. Read more in our <a href="/p/disclosure">Disclosure</a>.</p>
<h2>Corrections</h2>
<p>If you find an error, write to <a href="mailto:info@techmediaarch.com">info@techmediaarch.com</a> with the link to the answer and what is wrong (see <a href="/p/contact-us">Contact Us</a>). Errors are checked and fixed, and a corrected answer shows an "Updated" date next to the publication date.</p>
<h2>What Tech Media Arch is not</h2>
<p>Tech Media Arch is an answer archive, not a news agency. It does not interview sources and is not a member of a press complaints body. Answers are general information, not financial, legal or security advice for your situation.</p>
